🐸 BlockFrogs preview v2 renderer · nothing is inscribed

Type Bitmap block heights, then press Render. Each frog is drawn by the real blockfrogs-child.v2.html (a PREVIEW build of it) in two hosts: a plain browser, which runs its own three.js view, and the official MML web client, which runs its MML path.

Up to 6 heights, comma- or space-separated. Each frog uses 2 WebGL views.

Block data

On chain, the rare traits come from the hash of the block in which the child inscription confirms (/r/inscription/<own id> → /r/blockhash/<that height>), not from the Bitmap's block. That hash isn't known until the frog is inscribed, so the preview stands in for it.

Traits

Click a box to cycle it: – auto (from the block), ✓ forced on, ✕ forced off. Changing anything switches to Custom.

Local preview only. Block data is fetched live from ordinals.com or mempool.space (both send Access-Control-Allow-Origin: *). Models come from glb/ (the 63 v2 glb-min files) through preview inscription ids (ids-map.json). three.js is r178 from lib/. The MML client is mml-client.min.js, built from @mml-io/mml-web 0.26.1. No CDN is used.
